# Character Animation Player

A simple interactive sprite animation demo built with HTML5 Canvas and JavaScript.  
Users can switch between different character animations using a dropdown menu.

## Features

- Smooth sprite sheet animations
- Multiple animation states:
  - Idle
  - Jump
  - Fall
  - Run
  - Dizzy
  - Sit
  - Roll
  - Bite
  - KO
  - Get Hit
- Easy animation switching via dropdown
- Responsive canvas rendering

## Demo

Open `index.html` in your browser to try it out.

## How to Run

1. Clone or download this repository
2. Open the project folder
3. Open `index.html` in any modern browser  
   (or use Live Server in VS Code)
